# Changelog

## 0.1.0 — 2026-10-13

First public source release as **PageNest PDF**, previously developed locally as Gemini PDF Reader.

- Includes the existing local PDF.js reader, themes, highlights and notes, bookmarks, reading statistics, history and tab/window session recovery.
- Includes the optional Manifest V3 companion with local-file bridging and HTTP Range/progressive transfer.
- Updates the browser title and extension display names; retains existing browser storage identifiers and bridge protocols.
- Reorganizes documentation into a concise README, reader/development guides and a dated verification record.
- Excludes dependencies, generated builds, editor settings and personal incident reports from source control; preserves useful historical acceptance evidence under `docs/archive/`.

See [verification](docs/verification.md) for checks and outstanding manual acceptance. Source publication is separate from website deployment and Chrome Web Store distribution.
